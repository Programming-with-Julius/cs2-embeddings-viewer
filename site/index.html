Embeddings Viewer

Programming with Julius

These are UMAP embeddings visualized in 3D space, representing activations from a trained neural network. The network predicts the in-game location (XYZ) based on CS2 screenshots. The activations from the penultimate layer are reduced to 3D to create these maps.

The multihead model also predicts which map the screenshot is from, resulting in a dramatically different embedding space. The default model only predicts the in-game location.

The 3D visualization is not optimized for mobile devices. For the best experience, use a desktop or laptop computer.
